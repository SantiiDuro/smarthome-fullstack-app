# SmartHome Fullstack Application

Fullstack smart home management platform with a **.NET 8 REST API**, **Angular frontend**, and **SQL Server database**.

This project was developed as part of the **Software Design II course at ORT Uruguay**.

## Team

- Santiago Duró
- Lucas Facello
- Federico Katz

## Technologies

- .NET 8 (Web API)
- Angular
- SQL Server
- Docker
- Bootstrap

## Features

- Smart device management
- User roles and permissions
- Room-based device organization
- Device importers (JSON, XML, etc.)
- REST API
- Angular SPA frontend

## Getting Started

### Requirements

- Docker
- .NET 8 SDK
- Node.js

1. Clone the repository

git clone https://github.com/SantiiDuro/smarthome-fullstack-app.git
